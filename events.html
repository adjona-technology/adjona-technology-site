Reducing Admin Work with Microsoft 365

Many organisations rely on email, spreadsheets, shared folders and informal reminders to manage important day-to-day work. Over time, this leads to missed follow-ups, unclear ownership, duplicated effort and poor visibility. This practical session looks at how Microsoft 365 can help you reduce manual admin and build clearer ways of working — with a focus on shared inboxes, routine admin processes, and task tracking and follow-up.

An example pattern for assisted inbox triage using a shared mailbox
